# Update Graphics

`vitadhoc-1.3-update.png` (1800 x 1200) is the 1.3 announcement image, in the
project's update-image series: a charcoal diagonal text area, cyan UPDATE, a
large white version number and PS VITA. It is laid out in HTML and rendered
headless; the three pictures in it are unretouched captures from a PS Vita
running 1.3 (`store/screenshots/vita-1.3/`: the SNES shelf, split screen,
Doom). It is promotional artwork, not a performance result.

`vitadhoc-1.2-update.png` is the 1.2 announcement image. Three conceptual
handheld systems flow into a Vita-shaped destination; it was generated with an
image model, then resized for export. It is not a product photograph, game
screenshot or performance result. No manufacturer wordmarks or separate app
logo mark are shown.
