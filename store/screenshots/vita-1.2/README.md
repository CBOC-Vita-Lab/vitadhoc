Captured on 2026-11-03 with the already-installed VitaCompanion 1.10 display
capture command. Every selected capture returned `rc=0`, a nonzero app PID,
960 x 544 dimensions and a fresh display-vblank counter before download.
No experimental USB recorder or kernel module was installed or activated.

The game images use full-screen stretch, CPU xBRZ and Enhanced 3x processing,
with Wide view off. The in-app FPS counter was disabled. All are direct
display-plane captures, not raw 240 x 160 cartridge-frame screenshots.

BMP captures were converted losslessly to RGB PNG and metadata was removed.
No game pixels, colours, text or smoothing were generated or retouched.
The ROM, BIOS, saves, raw device logs and private configuration are not
included. See [Performance](../../../docs/PERFORMANCE.md) for conditions.
