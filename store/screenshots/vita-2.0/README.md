# Physical Vita Captures (2.0)

Captured on 2026-11-27 on a physical PS Vita running VitAdhoc 2.0 (`rc7`, 500 MHz via PSVshell, 4-core Auto), with VitaCompanion's display capture command (the app's own display plane, `960 x 544`). The games are the tester's own dumps and homebrew test ROMs.

| File | Scene |
| --- | --- |
| `home.png` | VitAdhoc 2.0 home screen: box art grid, hero background, Wikipedia description, Triangle console picker (`Game Boy Advance`), `Play / Cover / Lists` pills, and live `Checking covers: 249 of 930` progress |
| `gba-wide.png` | *Golden Sun* (Vale rainstorm) in default GBA Wide View (`On + any game`, Soft edges) filling the 16:9 screen with zero stretching at locked 60.0 fps |
| `gba-unbound-60fps.png` | *Pokemon Unbound* battle running at locked 60.0 fps (up from 34.08 fps before the generic SMC cache upgrade) with default Ambient Glow |
| `gbc-4x-xbrz.png` | `cgb-acid2` on Game Boy Color (Gambatte Accurate) at the new default `4x xBRZ` supersampling (`640 x 576` scaled cleanly to `604 x 544` Fit) with Ambient Glow at locked 60.0 fps |

The in-app FPS counter was off. Raw display-plane captures were converted losslessly to RGB PNG with metadata stripped; no game pixels, colours, text, or smoothing were generated or retouched. No ROM, BIOS, save, or private configuration is included. See [Performance](../../../docs/PERFORMANCE.md) for the full real-hardware measurements.

Game imagery belongs to its respective creators and rights holders; these screenshots illustrate compatibility and display output, not included games.
