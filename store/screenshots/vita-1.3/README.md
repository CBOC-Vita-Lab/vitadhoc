# Physical Vita Captures (1.3)

Captured on 2026-11-07 on a PS Vita running the VitAdhoc 1.3 release
candidate, with VitaCompanion 1.10's display capture command (the app's own
display plane, 960 x 544). The games are the tester's own cartridge dumps.

| File | Scene |
| --- | --- |
| `home-snes.png` | The home screen's SNES shelf: downloaded box art, the game's title screen behind, its Wikipedia description |
| `snes-original.png` | Yoshi's Island (Super FX 2) in the default Original shape with the side glow |
| `snes-crt.png` | Super Mario World with CRT scanlines at 5 |
| `snes-picture.png` | The SNES pause menu's Picture page (L + R + Start) |
| `snes-superfx.png` | Doom (Super FX 2) at full game speed |
| `split-screen.png` | Two players on one Vita: Mario Kart: Super Circuit side by side |
| `covers.png` | The Cover picture page for a SNES game |
| `gba-fit.png` | A GBA game without a Wide view profile: its own shape, glow in the sides |

The in-app FPS counter was off. The picture settings changed for
`snes-crt.png` were put back afterwards. BMP captures were converted
losslessly to RGB PNG and metadata was removed; no game pixels, colours,
text or smoothing were generated or retouched. No ROM, BIOS, save or private
configuration is included. See [Performance](../../../docs/PERFORMANCE.md)
for the measurements.

Game imagery belongs to its respective creators and rights holders; these
screenshots illustrate compatibility and display output, not included games.
