# Update Graphic

`vitadhoc-1.2-update.png` is promotional artwork for the 1.2 announcement.
It follows the project's update-image series: a charcoal diagonal text area,
cyan UPDATE, a large white version number and PS VITA.

Three conceptual handheld systems flow into a Vita-shaped destination.
The illustration was generated with an image model, then resized for export;
it is not a product photograph, game screenshot or performance result.
No manufacturer wordmarks or separate app logo mark are shown.

The physical gameplay captures are in `store/screenshots/vita-1.2/`.
