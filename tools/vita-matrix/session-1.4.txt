# VitAdhoc 1.4 owner session plan, one unattended run (python3 matrix.py session-1.4.txt).
# Format: game | duration | key=value ... | label
#   plain keys -> vita.ini (test switches), t.<key> -> snes/threads.ini,
#   c.<key> -> config.ini (merged into the owner's own Settings, restored at the end).
# Keys (final names):
#   smooth_smooth_handoff=0|1   frame hand-over (draw on its own thread); handoff_check=0 keeps it on
#   look_gov=0|1         look governor (Auto picture quality)
#   core4=off|auto       fourth CPU core (needs the CapUnlocker plugin; t.core4 for SNES)
#   c.quality_gba=N      Image quality: 0 Auto, 1 Original, 2 xBRZ 2x, 3 xBRZ 3x, 4 xBRZ 4x, 5 MMPX 2x
#   jit_lazy_exits=1     GBA lazy translation A/B (shipped off); read vita_jit_worst
#   t.draw_core=1|2      SNES draw thread core; t.wide_policy=0 SNES wide ladder off
# Read per entry: handoff: vc_miss= (missed refreshes: 0 = locked 60), look:, vita_jit_worst,
# SNES t= / A t= / wide ladder: / superfx clock.
# Each entry starts from an EMPTY vita.ini / threads.ini plus these keys, so a row is
# never coloured by the owner's own files (they are put back at the end).
#
# Layers, one at a time, on every GBA game: baseline (all three off), +hand-over,
# +governor, +core4, then everything on.  60 s each (about 3600 frames).
