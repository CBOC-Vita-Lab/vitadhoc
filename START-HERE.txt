VitAdhoc 1.3.1
Game Boy Advance, Game Boy, Game Boy Color, Super NES and NES for PS Vita

Thanks for trying VitAdhoc! Here's everything you need to get playing.


What You Need
- A PS Vita with HENkaku or Enso, and VitaShell
- Your own .gba, .gb, .gbc, .sfc, .smc or .nes games
- No BIOS needed: an open one is built in


Easy Install
Open the CBOC Vita Installer on your computer and drop VitAdhoc.vpk (or this
whole ZIP) onto it. Add your games if you like. It finds your Vita and does
the rest.
https://github.com/CBOC-Vita-Lab/vita-installer/releases


Manual Install
1. Copy VitAdhoc.vpk to your Vita with VitaShell (USB or FTP) and install it.
2. Start VitAdhoc once. It creates ux0:data/GBAdhoc/
3. Put your games in ux0:data/GBAdhoc/roms/
   (games already in ux0:ROMS/, any folder inside it, or RetroFlow's folders
   are found by themselves)
4. Start VitAdhoc again and pick a game.


Updating
Just install the new VPK over the old one. Your games, saves, states and
settings stay where they are. 1.3 moves save states and thumbnails out of
your game folders into ux0:data/GBAdhoc/ the first time each game is opened.


Saves From Another Emulator
Put the save next to the game (Game.srm, or Game.sav for a Game Boy game) or
in ux0:data/GBAdhoc/import/. VitAdhoc takes it in the first time you start
that game, as long as the game has no save here yet. Details: INSTALL.md.


Have Fun
- Hold Start + Select (or tap the screen) for the menu.
- In a SNES game, hold L + R + Start for its menu.
- Press Start on the home screen for Settings, including RetroAchievements.
